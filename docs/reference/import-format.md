# JSON 导入格式

状态：已确认

第一版每个 JSON 文件表示一个卡组，使用 UTF-8 编码。示例：

```json
{
  "title": "初中物理",
  "description": "力学知识点",
  "cards": [
    {
      "title": "惯性",
      "content": "物体保持原有运动状态的性质。",
      "speechText": "物体保持原有运动状态的性质。",
      "memoryTip": "质量越大，惯性越大。"
    },
    {
      "title": "速度",
      "content": "单位时间内通过的路程。"
    }
  ]
}
```

| 字段 | 类型 | 规则 |
|---|---|---|
| `title` | 字符串 | 卡组名称，去除首尾空格后非空 |
| `description` | 字符串 | 可选；空字符串按未填写处理 |
| `cards` | 对象数组 | 必填，1 到 1000 张；数组顺序就是卡片顺序 |
| `cards[].title` | 字符串 | 必填，去除首尾空格后非空 |
| `cards[].content` | 字符串 | 必填，去除首尾空格后非空 |
| `cards[].speechText` | 字符串 | 可选；留空时使用正文朗读和匹配 |
| `cards[].memoryTip` | 字符串 | 可选；留空时背面显示占位文字 |

文件最大 2 MiB。缺少可选字段与可选字段为 `null` 都按未填写处理；其他字段类型错误会拒绝整个文件。未知字段忽略。导入时只使用内容字段，外部 ID、时间戳、学习位置与记录不会写入。

重复导入按规范化后的卡组名称、说明及卡片内容判断，不按文件名判断。同一内容再次导入会打开已有卡组；同名而内容不同会提醒后创建新卡组。
