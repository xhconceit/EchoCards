# 节点 1：目标真机语音探针

状态：未开始  
返回：[开发总览](README.md)

交付：固定卡片的 TTS、识别、麦克风权限及生命周期适配。该节点先于完整页面开发。

开发清单：

- [ ] 建立 `domain/speech` 事件与接口，事件携带 `operationId`。
- [ ] 实现 `speech/android` 的 TTS、识别、权限与音频焦点适配器。
- [ ] 用固定卡片接通“朗读→识别→完成”探针页面。
- [ ] 取消或切卡时先使旧 ID 失效，再停止系统服务。
- [ ] 处理后台停麦、权限拒绝和服务缺失，记录目标真机结果。

| 用例 | 操作与预期 | 状态 |
|---|---|---|
| V01 | 在目标真机启动普通话朗读；实际听到声音并收到一次完成事件。 | 未执行 |
| V02 | TTS 完成前不启动识别；完成后再收音，并收到部分或最终识别结果。 | 未执行 |
| V03 | 识别期间切卡或取消；随后到达的旧回调不改变当前卡片。 | 未执行 |
| V04 | App 进入后台；麦克风停止使用，回到前台不自动重新收音。 | 未执行 |
| V05 | 拒绝权限或设备缺少语音服务；页面说明原因且仍可进入手动模式。 | 未执行 |
