# 知声卡第一版需求

状态：已确认

## 一、基本规则

- 第一版仅支持 Android，不包含 iOS、Web 或其他平台客户端。
- 第一版只保证普通话朗读与跟读识别，卡片编辑界面不显示语言字段。
- 一个卡组包含多张知识卡片，一张卡片表达一个知识点。
- 卡片包含标题、正文、可选跟读文本和可选快速记忆点。
- 跟读文本为空时，使用正文朗读和匹配；标题和快速记忆点不参与跟读。
- 卡片正面显示标题和正文，点击后翻到快速记忆点；未填写时背面显示“暂无快速记忆点”。
- 卡组、卡片、设置、学习位置和学习记录保存在本机。
- 首次安装不预置示例卡组，显示创建第一个卡组的引导。

## 二、功能需求

### DECK-001 卡组首页

- 首页提供按卡组名称搜索。
- 卡组项显示名称、卡片数量和上次学习位置，不显示“已掌握”或掌握率。
- 第一版不提供“今日复习”或复习计划。
- 底部导航包含“首页”和“我的”。
- “我的”提供默认学习模式、朗读速度和自动翻页延迟设置。
- 选择学习模式的弹层默认突出“我的”中设置的模式，用户仍可选择其他模式。

### DECK-002 卡组管理

用户可以创建、重命名、修改说明和删除卡组。

验收条件：

- 卡组名称去除首尾空格后不能为空。
- 删除前二次确认，并提示会同时删除组内卡片。
- 空卡组显示“添加第一张卡片”，且不能开始学习。

### CARD-001 卡片管理

用户通过底部弹层新增、编辑和删除卡片，并能调整顺序。

验收条件：

- 标题和正文必填；跟读文本和快速记忆点选填。
- 编辑界面不显示语言和标签字段。
- 删除卡片前需要二次确认。
- 保存后重新打开，内容和顺序保持一致。
- 修改正文或跟读文本时，卡片版本加 1。

### DATA-002 从外部文件导入卡片

- 首页提供“导入卡组”，通过 Android 系统文件选择器读取设备或其他应用提供的 UTF-8 JSON 文件，无需存储权限。
- JSON 顶层是一个卡组对象，包含 `title` 和非空 `cards` 数组；可选 `description`。每张卡片包含 `title` 和 `content`，可选 `speechText`、`memoryTip`。字段名区分大小写，额外字段忽略，示例见 [JSON 导入格式](../reference/import-format.md)。
- 卡组名称默认使用 JSON 中的 `title`，导入前可修改；不覆盖现有卡组。
- 导入前比较规范化后的卡组名称、说明和有序卡片内容（含可选字段）。若与现有卡组内容完全相同，提示“已有相同内容的卡组”并打开该卡组，不重复创建；修改预览名称也不能绕过此判断。即使原导入卡组之后被编辑，重复导入同一份原始数据仍识别为重复。
- 仅名称相同但内容不同，提示“将新增同名卡组”，用户仍可导入；不同文件名、JSON 字段顺序或无关字段不影响重复判断。删除原卡组后允许重新导入。
- 必填字符串去除首尾空格后不能为空。文件为空、JSON 格式损坏、字段类型不符或任一卡片无效时，显示字段或卡片序号并取消整次导入，现有数据不受影响。
- 导入前显示卡组名和有效卡片数量，用户确认后一次性保存；按数组顺序排列卡片，初始版本为 1，学习位置为第一张。
- 限制文件大小为 2 MiB、卡片数为 1000 张；超限时给出提示。导入完成或失败后均可再次选择文件。

### LEARN-001 开始与恢复学习

- 卡组详情使用一个“开始学习”按钮，点击后选择手动学习、自动跟读或自动播放。
- 用户可以在学习页面点击当前模式名称切换模式。
- 切换模式时停止当前语音任务，并从当前卡片重新开始。
- 再次进入卡组时从上次离开的卡片继续。
- App 冷启动回到首页，不自动恢复学习页面、朗读或麦克风。

### LEARN-002 卡片浏览

- 左滑进入下一张，右滑返回上一张。
- 最后一张左滑循环到第一张，第一张右滑循环到最后一张，三种模式行为一致。
- 页面只显示当前位置，例如 `3 / 20`，不显示顶部进度条或循环轮次。
- 点击卡片翻面；没有快速记忆点时背面显示“暂无快速记忆点”。
- 一次手势只切换一张卡片，切换后停止上一张的语音任务。

### LEARN-003 手动学习

- 手动模式显示朗读控制，支持播放、暂停和继续。
- 朗读内容为跟读文本，未设置时使用正文。
- 退出页面或切换卡片时停止当前朗读。

系统 TTS 没有统一的原句内暂停/继续能力。实现可按句子或短语分段朗读并保存分段位置；无法精确恢复时，从当前分段开头继续。

### LEARN-004 自动跟读

流程为：朗读正面内容 → 等待用户跟读 → 判断读完 → 自动翻到快速记忆点 → 短暂停留 → 下一张。

验收条件：

- 朗读期间不进行识别，朗读完成后才开启麦克风。
- 只显示状态文案（正在朗读、轮到你读了、快速记忆点、学习已暂停），不展示完整识别文本、覆盖率或评分。
- 覆盖率仅供内部判断是否完成跟读，不作为学习进度显示。
- 用户只读开头不能自动切换卡片。
- 每次完成只前进一张，旧回调不能影响当前卡片。
- 控制项包括暂停、继续和重读。
- 用户主动左右切卡时停止当前朗读和识别，不记录为跟读完成。

### LEARN-005 自动播放

流程为：使用系统语音朗读正面内容 → 自动翻到快速记忆点 → 按设置停留 → 下一张。

验收条件：

- 自动播放使用真实系统语音，不使用固定时长假装朗读完成。
- 控制项包括暂停、继续和播放速度。
- 没有快速记忆点时仍然翻面并显示占位文字。

### LEARN-006 退出和后台行为

- 用户退出学习时直接停止朗读和麦克风、保存当前位置并返回卡组详情，不显示结果页或退出确认。
- App 进入后台、来电或音频中断时暂停自动流程并关闭麦克风。
- 返回前台后保持暂停，由用户主动继续。
- 学习持续循环，不提供“本轮完成”或学习结果页面。

### DATA-001 本地保存

- 保存卡组、卡片、排序、设置、各卡组当前位置和学习记录。
- 正常关闭并重新打开 App 后数据保持一致。
- 恢复位置时不恢复未完成的录音、朗读进度或半句识别文本。
- 看过和跟读完成分别记录；主动切卡不产生跟读完成记录。
- 第一版不保存原始录音或完整识别文字。

### ERROR-001 权限和异常

- 首次进入自动跟读时先说明麦克风用途，再请求系统权限。
- 权限或识别服务不可用时说明原因，并提供重试、打开系统设置和切换手动学习。
- 朗读或保存失败时保留当前卡片并提供重试。
- 本地卡片在无网络时仍可阅读。
- 不承诺所有设备均支持离线朗读或离线识别。

## 三、第一版不包含

- 账号登录和跨设备同步
- AI 自动生成卡片
- 发音评分
- 知识掌握程度判断
- 今日复习和智能复习计划
- 卡片标签
- 多语言语音支持
- 后台持续跟读

## 四、待验证事项

- 目标 Android 机型的普通话朗读和识别服务可用性
- 不同品牌和系统版本的识别表现
- 漏字、重复和停顿时的匹配规则
- 自动翻页准确性和等待时间
- 分段 TTS 对手动暂停和继续体验的影响
